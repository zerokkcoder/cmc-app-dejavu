# DÉJÀVU · 市场既视感（中文）

[English](../README.md)

## 一句话

把 CMC 的六类第一方数据合成「市场状态指纹」，在 1000+ 天历史里找出最像今天的日子，然后展示那些日子之后 7/30/90 天真实发生了什么。

赛道：**Data and Visualisation** · 赛事：Build with CMC: API Hackathon Round 2 (Plushie)

## 目标用户与痛点

- **用户**：加密研究员、宏观/量化分析师、RWA 与趋势观察者、需要讲清「现在处于周期哪个位置」的内容创作者。
- **痛点 1**：情绪工具只看 Fear & Greed 或 BTC 主导率一个维度，无法回答「现在像历史上的哪一段」。
- **痛点 2**：回测工具给策略收益，不给「相似状态之后的真实市场路径」这种直觉答案。
- **痛点 3**：多数「历史相似」产品依赖交易所数据或自采数据；用 CMC 第一方指数做多维指纹、无前视偏差近邻匹配和 2D 星图的产品未见同类。

## 竞品差异

| 维度 | DÉJÀVU | 常规行情/回测 | 情绪仪表盘 |
|---|---|---|---|
| 视角 | 多维状态 → 历史近邻 | 单指标 / 策略回测 | 单指标当前值 |
| 输出 | 相似日 + 之后真实路径 | 指标曲线 | 一个分数 |
| 严谨性 | 扩展 z-score、排除前视与自身窗口 | 通常不处理 | 无 |
| 数据 | CMC 第一方指数 + 全球指标 | 交易所数据 | 单一指数 |

## MVP 范围

单屏暗色「天文台」界面：Header、自动生成的反直觉洞察、API 脉搏条、PCA 星图、指纹雷达、8 张近邻卡、时间轴、+90 日路径图、常驻免责声明。中英双语切换、响应式、空态/错误态。

不做：合约、钱包、链调用、数据库、多页、登录、WebSocket、外部数据源。

## 目录结构

- `app/` — 单屏与 `/api/state`
- `components/` — 9 个可视化组件
- `lib/cmc/` — 服务端 API 客户端、端点常量、字段归一化
- `lib/analytics/` — 指纹、距离、PCA、前向收益、洞察生成
- `scripts/` — 端点探测、真实快照构建、演示快照构建
- `data/` — `snapshot.json`、`manifest.json`、`evidence/`
- `docs/` — 中英双语文档
